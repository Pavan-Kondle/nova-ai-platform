
# NOVA AI Platform

NOVA is an AI-powered workflow orchestration and permit automation training project.

## Planned technology stack

- Next.js
- TypeScript
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Azure/GCP
- RAG

## Project Goals

- Build a production-style full-stack application
- Learn professional Git workflows
- Implement REST APIs and PostgreSQL persistence
- Integrate RAG and Generative AI
- Deploy to Azure or GCP
