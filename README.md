
# NOVA AI Platform

NOVA is a cloud-native platform for AI workflow automation and intelligent business processes.

## Planned technology stack

- Next.js
- TypeScript
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Azure/GCP
- RAG

## Project Goals

- Build a production-style full-stack application
- Learn professional Git workflows
- Implement REST APIs and PostgreSQL persistence
- Integrate RAG and Generative AI
- Deploy to Azure or GCP
